# socai-core

`socai-core` is the shared Rust runtime used by the socai CLI and desktop app.
It provides browser-session management, agent execution, media processing, and
social-platform research primitives.

Most users should install the `socai` CLI or desktop app rather than depend on
this crate directly. See [socai.io](https://socai.io) and the
[socai repository](https://github.com/socai-io/socai) for usage and releases.
