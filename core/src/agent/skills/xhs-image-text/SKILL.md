# 小红书图文文案提取

## 使用与范围

用户要求小红书图文文案提取时读取本 skill。用户的原始目标、平台、数量、预算和权限优先；这份方法不证明依赖工具、登录、下载、转写、调度或发送能力已经可用。先检查本次工具 schema、真实页面状态和输入身份，再执行。

小红书：保留原作品定位所需参数，使用已暴露的 search/get_notes/author_scan 或站点 manifest 工具，严格以当前 schema 为准。get_notes 已支持的下载、OCR、逐字稿选项按需要开启；用 read_saved_notes 分页读已保存数据，不为取回截断文本反复采集。

## 操作方法

先获取本作品封面及所有目标配图的真实列表和顺序；用实际图片/OCR能力逐张识别，不把标题或笔记正文当图片识别结果。保留图片序号、来源、原始识别文字和失败原因；阅读顺序优先页面顺序，不把多张文字直接拼成一段而丢定位。金额、单位、参数、人名等关键字段对照原图，低置信或不可辨识处标注，不用模型补成事实。用户只需要原文时保留原文字段；纠错、整理和摘要另列。将文字与同一作品记录/已下载图片关联，供后续检索、拆解和导出复用。

## 交付与完成条件

按图片顺序的逐图文字、作品及图片定位、识别成功/失败数量、需要人工核对的关键字。

开始、失败或部分完成都要在当前任务中保留实际步骤和来源。正文、评论、图片、音频、文件或监控的缺失不能用示意数据、推测内容、接口200或构建成功代替。遇到登录、验证码或风控交由用户正常接管，不自动绕过，不重复提交未知结果的写操作。跨任务学习不存放用户资料或平台原文。
