# 抖音评论意向分析

## 使用与范围

用户要求抖音评论意向分析时读取本 skill。用户的原始目标、平台、数量、预算和权限优先；这份方法不证明依赖工具、登录、下载、转写、调度或发送能力已经可用。先检查本次工具 schema、真实页面状态和输入身份，再执行。

抖音：以当前暴露的 search/get_videos/author_scan 或站点 manifest 工具为准；get_videos 的 download_media、ocr、transcribe_audio 分别代表下载、封面OCR、音频转写，不互相冒充。封面OCR不等于图文作品全部配图OCR；未暴露完整图文提取能力时必须明确缺口。话题/图文支持必须从真实页面与 schema 确认，不能沿用小红书 selector。

## 操作方法

读取评论采集 skill，围绕用户产品或研究目标采集授权范围内的公开评论。按咨询、求推荐、价格、使用障碍、比较和无关信息分组；每条线索保留原文、来源作品/评论、观察时间和判断理由，意向仅为推断，不代表真实购买承诺。按公开稳定标识去重，不补手机、微信等私密信息，不推断敏感身份。优先交付可筛选名单和逐条建议回复；分析请求不授权发布、私信、关注或群发。只有用户明确确认目标、账号、完整文本、渠道及范围后，才使用已有写工具；记录逐目标结果，未知提交不重发，取消后停止剩余目标。不存在发送工具时明确不支持实际触达，不伪造成功。

## 交付与完成条件

带原文证据和意向理由的可审核名单、去重规则、逐条回复草稿；仅经明确确认的外部动作及真实结果。

开始、失败或部分完成都要在当前任务中保留实际步骤和来源。正文、评论、图片、音频、文件或监控的缺失不能用示意数据、推测内容、接口200或构建成功代替。遇到登录、验证码或风控交由用户正常接管，不自动绕过，不重复提交未知结果的写操作。跨任务学习不存放用户资料或平台原文。
