# 抖音爆款分析

## 使用与范围

用户要求抖音爆款分析时读取本 skill。用户的原始目标、平台、数量、预算和权限优先；这份方法不证明依赖工具、登录、下载、转写、调度或发送能力已经可用。先检查本次工具 schema、真实页面状态和输入身份，再执行。

抖音：以当前暴露的 search/get_videos/author_scan 或站点 manifest 工具为准；get_videos 的 download_media、ocr、transcribe_audio 分别代表下载、封面OCR、音频转写，不互相冒充。封面OCR不等于图文作品全部配图OCR；未暴露完整图文提取能力时必须明确缺口。话题/图文支持必须从真实页面与 schema 确认，不能沿用小红书 selector。

## 操作方法

先确认赛道、时间窗和用户的爆款/低粉阈值，未提供时说明采用的样本内标准，不杜撰平台标准。采集匹配作品，按唯一作品 ID 去重，补作者粉丝、发布时间和可见互动，再挑高、中、低互动对照，避开只挑爆款的偏差。点赞、收藏、评论分别统计；播放量或粉丝缺失留空，分母为零时倍数留空。回读代表作品正文、图片文字、真实逐字稿及评论，拆解标题、开头、信息结构、视觉和行动引导；未看视频不能声称验证镜头、口型、剪辑或精确秒点。把可迁移模式和偶然因素分开，不把相关性称为增长原因。

## 交付与完成条件

带原作链接的样本表、样本内指标与基线、内容拆解、可迁移选题及证据不足项。

开始、失败或部分完成都要在当前任务中保留实际步骤和来源。正文、评论、图片、音频、文件或监控的缺失不能用示意数据、推测内容、接口200或构建成功代替。遇到登录、验证码或风控交由用户正常接管，不自动绕过，不重复提交未知结果的写操作。跨任务学习不存放用户资料或平台原文。
