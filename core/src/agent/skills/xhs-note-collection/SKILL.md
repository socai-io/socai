# 小红书作品采集

## 使用与范围

用户要求小红书作品采集时读取本 skill。用户的原始目标、平台、数量、预算和权限优先；这份方法不证明依赖工具、登录、下载、转写、调度或发送能力已经可用。先检查本次工具 schema、真实页面状态和输入身份，再执行。

小红书：保留原作品定位所需参数，使用已暴露的 search/get_notes/author_scan 或站点 manifest 工具，严格以当前 schema 为准。get_notes 已支持的下载、OCR、逐字稿选项按需要开启；用 read_saved_notes 分页读已保存数据，不为取回截断文本反复采集。

## 操作方法

识别输入是作品、账号、关键词还是话题，不自动扩大范围；先用真实页面状态验证平台和内容身份。按本平台实际暴露的搜索、账号或详情工具采集，列表只有预览时明确标记，并按需求补正文、作者、发布时间、标签、互动、媒体和原链接。跨分页按稳定作品 ID 去重，保存已经取得的数据，明确 requested/collected、停止原因与断点。到达用户数量或真实列表结束才停止；登录、验证码、限流、超时或连续无新增时保留 partial，不谎称全部。导出用户需要的 CSV/Markdown，正确转义换行与公式开头文本，确认文件实际生成和可下载。

## 交付与完成条件

唯一作品记录、原链接、字段可得性、采集时刻、覆盖数量及停止原因；用户需要的可下载文件。

开始、失败或部分完成都要在当前任务中保留实际步骤和来源。正文、评论、图片、音频、文件或监控的缺失不能用示意数据、推测内容、接口200或构建成功代替。遇到登录、验证码或风控交由用户正常接管，不自动绕过，不重复提交未知结果的写操作。跨任务学习不存放用户资料或平台原文。
