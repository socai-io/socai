# 小红书内容工作流

## 使用与范围

用户要求小红书内容工作流时读取本 skill。用户的原始目标、平台、数量、预算和权限优先；这份方法不证明依赖工具、登录、下载、转写、调度或发送能力已经可用。先检查本次工具 schema、真实页面状态和输入身份，再执行。

小红书：保留原作品定位所需参数，使用已暴露的 search/get_notes/author_scan 或站点 manifest 工具，严格以当前 schema 为准。get_notes 已支持的下载、OCR、逐字稿选项按需要开启；用 read_saved_notes 分页读已保存数据，不为取回截断文本反复采集。

## 操作方法

先确认研究目标、平台、关键词或账号、样本上限与交付形式。读取本平台采集 skill，再按需要读取关键词、爆款、账号、评论、图片文字或视频逐字稿 skill；不要为单项请求跑完整流水线。第一轮先交付真实样本和带来源的候选选题，等待用户选择后，再在同一对话生成标题、提纲、正文或口播脚本。用户明确指定选题及要求直接写稿时，不重复增加选择步骤。品牌、产品、经历和成绩只使用用户资料；不移植对标账号事实。保留素材、结论、选题、稿件的对应关系，修改一段不重采全部内容。

## 交付与完成条件

样本清单、带出处的内容判断、可选择选题；选题确认后的可编辑初稿、事实缺口与素材授权提醒。

开始、失败或部分完成都要在当前任务中保留实际步骤和来源。正文、评论、图片、音频、文件或监控的缺失不能用示意数据、推测内容、接口200或构建成功代替。遇到登录、验证码或风控交由用户正常接管，不自动绕过，不重复提交未知结果的写操作。跨任务学习不存放用户资料或平台原文。
