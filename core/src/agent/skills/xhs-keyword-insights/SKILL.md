# 小红书关键词洞察

## 使用与范围

用户要求小红书关键词洞察时读取本 skill。用户的原始目标、平台、数量、预算和权限优先；这份方法不证明依赖工具、登录、下载、转写、调度或发送能力已经可用。先检查本次工具 schema、真实页面状态和输入身份，再执行。

小红书：保留原作品定位所需参数，使用已暴露的 search/get_notes/author_scan 或站点 manifest 工具，严格以当前 schema 为准。get_notes 已支持的下载、OCR、逐字稿选项按需要开启；用 read_saved_notes 分页读已保存数据，不为取回截断文本反复采集。

## 操作方法

若当前schema提供search_suggestions，优先用它采集每个种子词的真实可见联想，保留query、suggestions、collected_at和url；它不提交搜索并恢复原输入。suggestions_not_available或登录/验证码失败不是空需求、低搜索量或成功的0结果；保留失败并正常处理，不改用search结果页相关词或模型生成词冒充。该工具不代表已经完成a-z批量扩词，扩词必须单独说明预算与实际执行范围。

从种子词输入真实搜索框，读取可见下拉联想；用明确预算逐词扩展，去重并保留种子、实际扩展词、采集时间与来源。不能把模型生成词标成平台联想词；a-z 扩展仅在用户需要且页面允许时分批进行，不为凑数量高频访问。使用本平台搜索工具采集少量代表作品，按意图、人群、场景和问题聚类，比较作品重复率、互动分布和作者集中度；粉丝缺失时不判低粉账号。区分搜索样本、联想表达和模型建议，不将互动或联想排名称为搜索量、市场规模或全站竞争度。换词后刷新当前词数据，结束后恢复原搜索词。

## 交付与完成条件

去重关键词表（类型、种子、来源、意图）、真实样本及对标候选、优先方向和不确定性。

开始、失败或部分完成都要在当前任务中保留实际步骤和来源。正文、评论、图片、音频、文件或监控的缺失不能用示意数据、推测内容、接口200或构建成功代替。遇到登录、验证码或风控交由用户正常接管，不自动绕过，不重复提交未知结果的写操作。跨任务学习不存放用户资料或平台原文。
