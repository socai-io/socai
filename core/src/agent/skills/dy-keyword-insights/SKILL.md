# 抖音关键词洞察

## 使用与范围

用户要求抖音关键词洞察时读取本 skill。用户的原始目标、平台、数量、预算和权限优先；这份方法不证明依赖工具、登录、下载、转写、调度或发送能力已经可用。先检查本次工具 schema、真实页面状态和输入身份，再执行。

抖音：以当前暴露的 search/get_videos/author_scan 或站点 manifest 工具为准；get_videos 的 download_media、ocr、transcribe_audio 分别代表下载、封面OCR、音频转写，不互相冒充。封面OCR不等于图文作品全部配图OCR；未暴露完整图文提取能力时必须明确缺口。话题/图文支持必须从真实页面与 schema 确认，不能沿用小红书 selector。

## 操作方法

读取联想词时，优先调用本次已暴露的 `search`，参数为 `query` 原词及 `suggestions_only: true`。这是只读下拉流程，不提交作品搜索；工具用真实输入事件填词、等待两次稳定下拉、采集后恢复原输入。需要代表作品时才另行普通搜索，不把作品搜索登录失败冒充联想词采集失败。

底层 manifest 保留 `selectSearchInput`、`setSearchInput` 和只读 `searchSuggestions(query)`。只有当前 schema 确实暴露 `run_site_browser_tool` 时才直接调用这些页面工具；不能调用未提供的工具或为了读取下拉申请任意浏览器脚本权限。输入不匹配、旧词残留、空下拉或安全验证均不是成功。工具只返回当前实际标签，不提供搜索量；不能拿历史记录、视频标题或模型扩词冒充联想词。

从种子词输入真实搜索框，读取可见下拉联想；用明确预算逐词扩展，去重并保留种子、实际扩展词、采集时间与来源。不能把模型生成词标成平台联想词；a-z 扩展仅在用户需要且页面允许时分批进行，不为凑数量高频访问。使用本平台搜索工具采集少量代表作品，按意图、人群、场景和问题聚类，比较作品重复率、互动分布和作者集中度；粉丝缺失时不判低粉账号。区分搜索样本、联想表达和模型建议，不将互动或联想排名称为搜索量、市场规模或全站竞争度。换词后刷新当前词数据，结束后恢复原搜索词。

## 交付与完成条件

去重关键词表（类型、种子、来源、意图）、真实样本及对标候选、优先方向和不确定性。

开始、失败或部分完成都要在当前任务中保留实际步骤和来源。正文、评论、图片、音频、文件或监控的缺失不能用示意数据、推测内容、接口200或构建成功代替。遇到登录、验证码或风控交由用户正常接管，不自动绕过，不重复提交未知结果的写操作。跨任务学习不存放用户资料或平台原文。
