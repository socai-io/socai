# 抖音账号分析

## 使用与范围

用户要求抖音账号分析时读取本 skill。用户的原始目标、平台、数量、预算和权限优先；这份方法不证明依赖工具、登录、下载、转写、调度或发送能力已经可用。先检查本次工具 schema、真实页面状态和输入身份，再执行。

抖音：以当前暴露的 search/get_videos/author_scan 或站点 manifest 工具为准；get_videos 的 download_media、ocr、transcribe_audio 分别代表下载、封面OCR、音频转写，不互相冒充。封面OCR不等于图文作品全部配图OCR；未暴露完整图文提取能力时必须明确缺口。话题/图文支持必须从真实页面与 schema 确认，不能沿用小红书 selector。

## 操作方法

用主页链接和稳定作者 ID 确认对象，同名不能自动认作同一人。采集简介、可见粉丝与互动字段，以及用户范围内的公开作品；保留置顶、广告、异常和缺失字段标记。按高、中、低互动和主要主题分层取样，说明计划数量、实际数量、时间窗与覆盖限制，不默认所有账号均有50条作品。补代表作品正文、逐字稿、图中文字与评论，分别分析定位/受众、选题地图、标题与开头、信息结构、视觉、语言和互动反馈。每个结论关联具体作品，区分观察、推断和建议。输出可写选题前说明用户业务事实与对标风格的边界。

## 交付与完成条件

重做旧报告时，旧表只用于找到对象与线索，不能自动作为本轮事实依据；沿附件的原任务入口读取实际主页、作品与评论原件。账号累计指标与本次作品样本指标分开，不把不同口径相减推算遗漏互动，也不把按粉丝数归一化的点赞称为曝光、转化或商业效率。未覆盖的内容只写“所读样本中未见”，不写“该账号没有”。每个结论附具体作品链接；未读图片或真实音轨时不推断视觉或口播。

账号身份和样本范围、定位/主题/结构/视觉/语言报告、对照样本链接、可写选题和未验证判断。

开始、失败或部分完成都要在当前任务中保留实际步骤和来源。正文、评论、图片、音频、文件或监控的缺失不能用示意数据、推测内容、接口200或构建成功代替。遇到登录、验证码或风控交由用户正常接管，不自动绕过，不重复提交未知结果的写操作。跨任务学习不存放用户资料或平台原文。
